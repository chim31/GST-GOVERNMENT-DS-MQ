Tiny monospace grid marker — the ".01 / LABEL" data tags that punctuate the corners and rule lines of a poster.

```jsx
<DataTag index=".01" label="Bonne Action" />
<DataTag index="N°" label="Infos pratiques" tone="red" />
```

Use it near a Divider, at a block's baseline, or along the frame border. Keep the text short and technical — it reads as metadata, not a headline.
