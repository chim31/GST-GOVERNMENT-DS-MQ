Read the `readme.md` file within this skill, and explore the other available files (tokens in `tokens/`, components in `components/`, example posters in `ui_kits/posters/`, specimen cards in `guidelines/`).

If creating visual artifacts (posters, mocks, throwaway prototypes, etc.), copy assets out and create static HTML files for the user to view. If working on production code, copy the assets and read the rules here to become an expert in designing with this brand.

Core rules: square 1080×1080 format; 4-colour palette (teal `#0C7873`, red `#C42621`, cream/white, ink `#141414`), zero gradients; trio of fonts (Bebas Neue display / EB Garamond serif / IBM Plex Mono for data); hairline grid with crosshair nodes and mono `.01 / LABEL` data tags; lots of negative space; flat, editorial, never "Canva template". No emoji, no AI/3D illustration.

If the user invokes this skill without other guidance, ask them what they want to build (event announcement, countdown/deadline, greeting/vœux…), ask a few questions (title, date, place, price, contact), then act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.
