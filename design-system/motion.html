.01 / CINQ LOIS

Les lois

Elles s'appliquent à chaque pixel qui bouge, de la case cochée au bus qui décolle.

  1. .01

    L'éclosion d'abord

    Une surface éclot — un halo teal s'ouvre, puis le contenu monte en se précisant. Le contenu naît d'un lieu, jamais de nulle part ; aucun quadrillage n'est dessiné.

  2. .02

    Tout part d'un nœud

    Chaque animation a une origine visible : un point, un tag, le bouton touché. Les ondes, les tracés et les ouvertures partent de ce point.

  3. .03

    Le chiffre se calcule

    Un nombre ne remplace jamais un autre : il roule, colonne par colonne, de l'ancienne à la nouvelle valeur. « Le calcul est continu », rendu visible.

  4. .04

    L'éclair est rare

    Une seule animation Éclair par écran, réservée aux moments décisifs : seuil critique, budget validé, décollage.

  5. .05

    La beauté ne bloque jamais

    Aucune animation ne retarde une saisie de terrain. Tout est interruptible. prefers-reduced-motion → fondus de 120 ms, 3D figée sur son état final.

.05 / PILE & API

Dans le code

Stack de production recommandée : GSAP (ScrollTrigger, SplitText, DrawSVG) pour la vitrine et les séquences ; Motion pour l'UI React ; Lenis pour le défilement doux, sur la vitrine seulement ; Three.js via React Three Fiber + drei, chargés à la demande sur les deux pages 3D. Ce site de référence utilise un moteur vanilla de quelques kilo-octets qui implémente exactement les mêmes tokens.
